# ☁️ Quiz Cloud Practitioner (CLF-C02)

Um simulado web interativo, gamificado e responsivo, desenvolvido para auxiliar nos estudos e na preparação para a certificação oficial **AWS Cloud Practitioner (CLF-C02)**.

## 🚀 Funcionalidades Principais

* **🤖 Tutor Virtual (CloudBot):** Recepção personalizada com inserção de nome e feedback interativo de desempenho ao finalizar.
* **⚙️ Filtros Avançados:** Opção de escolher por nível de dificuldade (*Practitioner, Fácil, Médio, Hard*), além de customizar manualmente a quantidade de questões e o tempo limite.
* **⏱️ Cronômetro Integrado:** Acompanhamento do tempo decorrido em tempo real e relatório final de tempo gasto.
* **📚 Seção de Correção e Estudos:** Ao finalizar o teste, o usuário conta com um gabarito detalhado contendo explicações e botões de acesso direto à **Documentação Oficial da AWS**.
* **📱 PWA (Progressive Web App):** Pode ser instalado diretamente na tela inicial do celular para uso prático, inclusive offline.
